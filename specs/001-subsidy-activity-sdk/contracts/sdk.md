# SDK Interface: @gasmorph/sdk

## Scope
面向项目方快速接入补贴与消费券能力的 TypeScript SDK，需避免暴露或持有项目方私钥。

## Core Capabilities
- **补贴交易**: 对指定交易请求进行补贴，自动遵循控制台补贴开关。
- **消费券判定**: 依据用户是否持有消费券 NFT 决定抵扣路径。
- **活动发券**: 触发与控制台活动配置一致的发券流程。
- **券管理**: 支持消费券的转赠与销毁能力对外提供。

## Inputs (High-level)
- 项目标识与配置（非敏感）
- 目标链信息（chainId）
- 用户钱包地址与签名能力（由项目方提供）

## Outputs (High-level)
- 交易补贴结果（成功/失败/原因）
- 发券结果（voucherId、时间）
- 活动与补贴开关的状态读取

## Constraints
- SDK 不接收、不保存、不输出任何私钥或助记词。
- SDK 错误信息必须为英文，面向前端展示的提示仍为中文。
